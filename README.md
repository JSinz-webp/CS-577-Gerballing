**Gerballing** is a level based rolling ball game. The player controls a gerbil in a ball to roll down to the end of the level, avoiding traps and attempting to reach the end as fast as possible. There will be a selection of levels with an amount of stars rewarded given upon completing the level in a specified time. The main goal incentivizing the player to go fast to get the best time. 

Players can choose to spend stars collected on upgrades to the player controller such as an increased jump or reducing the size of the ball to avoid traps easier.
